# Scout abstract backgrounds

Six square, text-free backgrounds generated for Scout typography posts.

## Atmospheric set

1. `01-folded-navy.png` — folded navy material; quiet and editorial.
2. `02-paper-loop.png` — cream tactile loop on a dark field.
3. `03-vellum-current.png` — translucent plum layers and luminous particles.

## Screenprint set

4. `04-signal-rings.png` — cobalt search/signal rings on parchment.
5. `05-cropped-arches.png` — architectural fragments in cream, navy and rust.
6. `06-fabric-to-ink.png` — soft material translated into cobalt halftone.

All assets are 1:1 PNGs with no embedded typography. The original generated
files remain in the Codex generated-images directory.
