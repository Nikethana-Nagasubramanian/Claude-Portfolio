# Portfolio: slides and full stories

The public reading model has exactly two formats: **30-second slides** and **Full story**. The earlier paragraph summaries have been replaced by four moments per project. Homepage GrowthFactor opens the same story used on its case page. Shared copy and media live in `stories.js`; existing full articles remain in their HTML files.

## Voice and visual direction

Use a question someone might actually ask, explain personal ownership, show a consequential choice, and end with results or the current state. Keep the language conversational. Outcomes use only figures already in the case; interview exercises and personal tools stay clearly identified.

Instrument Sans carries the interface. Caveat is reserved for optional personal annotations, revealed with **My notes**. Loose circles, underlines and arrows give those notes a second voice without changing the navigation. Dark mode follows the system until explicitly changed, then remembers the selection across pages. Notes preferences also persist. Product screenshots retain their original colors.

## Interaction

Four moments with visible arrows, a position indicator, keyboard arrows within the viewer, and horizontal swipe. No auto-advance. The homepage uses a native dialog with Escape, focus containment and return to the trigger; the case pages embed the same player. Existing section links open the full story. `?read=short` now opens slides, preserving older links. Without JavaScript, the full article is available. Print includes the full article.
