Type Pattern

No input box, no enter key — just start typing anywhere on this page. Every letter, number, and symbol drops into a grid as a little shape, colour keyed to the character. Backspace erases the last one, same as any editor.

just start typing

start typing anywhere — letters, numbers, punctuation all render differently

Each key maps to a shape (letters → circles, numbers → triangles, symbols → diamonds) and a colour from a fixed palette keyed to the character code. The grid wraps and loops once it fills, so the pattern keeps evolving the longer you type.
