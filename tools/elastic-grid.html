Both demos share spring.js — position-based integration where a value's own momentum carries over each frame (damped) and a pull term eases it toward a target. The mesh runs one spring per axis per point, targeting each point's home position; the carousel runs one spring for the track offset, targeting the resting position of the nearest slide. Dragging pins the value directly to the pointer; releasing hands it back to the spring, momentum included.
